# 🏡 RentHub (房东管家) - 房源出租记账与凭据管理系统

基于 **Cloudflare Workers 边缘计算** 的高安全、极简轻便房屋租赁管理程序。
采用 **单一 Cloudflare D1 数据库 + 坚果云/OpenList WebDAV 端到端强加密直传** 的极致轻量化架构，**彻底免开 R2 存储桶，零绑卡门槛**，且深度针对 Cloudflare 免费配额进行极致节流。

## ✨ 核心特性

1. **🛡️ 纯粹安全与隐私至上**：
   - 支持主密码登录、手机 2FA（动态口令）、8 组紧急备用码、安全密保及安全邮箱找回，多重防护。
   - 未登录请求在 Cloudflare 网络边缘直接拦截，绝不泄漏任何后台业务数据。
2. **🔐 本地加密与 WebDAV 云盘双轨存储**：
   - 租房合同照片、交租单据原件支持 **D1 本地加密存储（零门槛开箱即用）** 或直传您的 **坚果云 / WebDAV 云盘**。
   - 文件采用 **AES-256-GCM** 算法加密，凭据照片与财务账目彻底解耦，删除凭据绝不误删账单。
3. **⚡ 极致轻量与零外置配置负担**：
   - 纯边缘无服务器运行，无需在 Cloudflare 后台手动配置繁琐的 Secret 环境变量，初始化向导自闭环开箱即用。
4. **💰 极致节流 Cloudflare 免费配额**：
   - 针对 Cloudflare 免费版限制彻底免开 R2，采用聚合查询与防篡改 Session，个人或小微房东每日开销不足免费配额的 0.1%。
5. **📱 Android 16 (Material 3 Expressive) 原生美学**：
   - 超大平滑圆角容器（`28px`）、胶囊药丸按钮、沉浸式卡片，完美适配手机端、微信内置浏览器与桌面端。
6. **💬 地道微信收据与交租提醒**：
   - 针对日常催租与收据沟通，提供一键生成自然、有礼貌的微信交租通知、结清收据与水电结算单。
7. **📧 纯房东待收提醒与定时预警**：

## 🚀 快速上手与本地调试

### 1. 安装依赖
确保本机已安装 Node.js (推荐 v20+)，在当前目录执行：
```bash
npm install
```

### 2. 初始化本地 D1 数据库
```bash
npm run db:migrate:local
```
此命令将在本地 SQLite 模拟环境中自动创建 `users`、`leases`、`payments`、`attachments` 及 `system_settings` 数据表。

### 3. 启动本地开发服务
```bash
npm run dev
```
终端会输出本地调试地址（通常为 `http://localhost:8787`）。

### 4. 首次访问与 2FA 绑定
1. 在浏览器中打开 `http://localhost:8787`。
2. 系统会自动识别为首次运行，并呈现 **首次初始化向导**：
   - 设置您的管理员用户名与主密码（至少 8 位）。
   - 点击「创建并生成 2FA」。
3. 系统将展示 **TOTP 密钥** 及 **8 组紧急备用恢复码**：
   - 打开手机中的验证器 App（如 **Google Authenticator**、**1Password**、**微软 Authenticator** 或 iOS 自带密码功能），手动输入密钥或点击链接添加。
   - **请务必截图或抄写备份 8 组恢复码**（手机丢失时可直接作为验证码登录）。
4. 点击「我已妥善保存，进入登录」完成初次登录，畅享管理后台！

## ☁️ 部署到 Cloudflare 生产环境 (保姆级教程)

本系统仅需要 Cloudflare 的免费 **Workers** 和免费 **D1 数据库**，不需要绑定信用卡！

### 第一步：登录 Cloudflare 授权
在终端执行：
```bash
npx wrangler login
```
浏览器会自动弹出 Cloudflare 登录页面，点击「Allow」授权即可。

### 第二步：创建线上 D1 数据库
在终端执行以下命令创建数据库：
```bash
npx wrangler d1 create zufang_db
```
执行完毕后，终端会打印如下输出信息：
```json
{
  "binding": "DB",
  "database_name": "zufang_db",
  "database_id": "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"
}
```

### 第三步：更新配置文件
打开当前目录下的 `wrangler.jsonc` 文件，将其中 `database_id` 的占位符替换为您刚刚生成的真实 ID：
```jsonc
  "d1_databases": [
    {
      "binding": "DB",
      "database_name": "zufang_db",
      "database_id": "替换为您真实的database_id" // 👈 粘贴在这里
    }
  ]
```

### 第四步：执行远程数据库建表
运行以下命令，将建表结构推送到 Cloudflare 线上 D1：
```bash
npm run db:migrate:remote
```
提示 `🌀 Executing on remote database zufang_db... Success!` 即表示数据库表初始化完成。

### 第五步：一键发布上线！
```bash
npm run deploy
```
稍等数秒，终端将输出您专属的生产环境访问域名：
```
https://renthub.<你的子域>.workers.dev
```
打开该链接，即可进入高安全公网服务！首次打开同样会引导您完成管理员 2FA 初始化。

## 📦 WebDAV 存储配置指南 (坚果云 / OpenList)

登录系统后，点击导航栏的 **「系统设置」**，即可配置您的加密文件直传渠道。

### 方式 A：坚果云 (Jianguoyun)
1. 打开 [坚果云官网](https://www.jianguoyun.com/) 并登录账号。
2. 点击右上角您的账户名 -> **「账户信息」** -> 切换到 **「安全选项」** 选项卡。
3. 找到 **「第三方应用管理」** -> 点击 **「添加应用密码」**。
4. 应用名称填写 `房东管家`，点击生成密码并复制该专用应用密码（注意：不是您的坚果云登录密码）。
5. 回到系统的「系统设置」页面：
   - 点击 **「坚果云预设」** 按钮，系统会自动填入地址：`https://dav.jianguoyun.com/dav/`
   - **用户名**：填写您的坚果云注册邮箱。
   - **应用密码**：粘贴刚才生成的专用应用密码。
   - **基础路径**：保持默认 `/RentRecords` 即可。
   - 打开右上角 **启用开关**。
   - 点击 **「测试连通性」**，提示成功后点击 **「保存配置」**。

### 方式 B：自建 OpenList / Alist
1. 确认您的 OpenList / Alist 服务已开启 WebDAV 支持（默认路径通常为 `/dav/`）。
2. 在系统设置中：
   - **服务器地址**：`http(s)://你的域名或IP:端口/dav/`
   - **用户名**：您的 OpenList 管理员或存储账户名。
   - **应用密码**：该账户对应的密码或 Token。
   - **基础路径**：挂载存储中的目标文件夹（如 `/aliyunpan/RentRecords`）。
   - 打开 **启用开关**，测试通过后保存。

## 🔒 密码学与灾难恢复机制

即使未来您不再使用 Cloudflare，存放在坚果云或 OpenList 中的文件也不会丢失：
* 文件名格式为：`[随机前缀]_[原始文件名].enc`
* 密文格式为标准的 `AES-256-GCM`，IV（初始向量）记录在数据库中，Tag 认证标签位于密文末尾 16 字节。
* 任何支持 Web Crypto 或 Python `cryptography` 库的单脚本均可离线解密全部文件。

## 🛠️ 常见问题排查

* **Q: 忘记了 2FA 动态码怎么办？**
  * 在登录界面的 2FA 步骤中，输入您在首次初始化时保存的任意一组 **8 位备用恢复码**（格式如 `A1B2-C3D4`），即可直接通过验证并自动消耗该组恢复码。
* **Q: 提示「未配置 WebDAV」无法上传凭证？**
  * 请进入顶部或底部导航栏的「系统设置」，开启 WebDAV 开关并填写坚果云或 OpenList 凭据后保存。
* **Q: 免费额度足够个人使用吗？**
  * 绰绰有余。Cloudflare 免费版每日提供 100,000 次 Worker 请求及 500 万次 D1 读操作。系统设计了高强度客户端缓存与单请求数据聚合，个人或家庭使用每日消耗量通常不足免费配额的 0.1%。
